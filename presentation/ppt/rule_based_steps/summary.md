# 룰베이스(구멍 개수 기반 형태 검증) 요약

완성된 조립체 사진에서 구멍 개수·위치·볼트 색으로 Model A/B/C를 판별하는 룰베이스 로직 —
CLAUDE.md 3-2 "최종 형태 검증" 필수 항목. `src/rule_based/hole_count_check.py`.

## 1. 핵심 로직 5단계

| # | 단계 | 내용 |
|---|---|---|
| 1 | 컨투어 검출 | `RETR_CCOMP`로 막대 외곽선과 내부 빈 구멍을 분리 검출 |
| 2 | 회전 보정 | 빈 구멍들의 직선 피팅으로 각도 추정 → 수평으로 되돌림 (기울어진 사진도 동일 로직) |
| 3 | 구멍 개수 세기 | 세로 막대(part_2hole/part_3hole)별 "접합점 위쪽 빈 구멍 개수"만 카운트. **색상 무관** — mother는 조립 후 컨투어가 합쳐져 직접 못 세서 세로 막대 기준으로 전환 |
| 4 | 레시피(시그니처) 대조 | Model A=[2,1] · B=[1,1] · C=[2]와 일치 여부 확인 |
| 5 | 배치(위치·색상) 검증 | 레시피의 정확한 구멍 번호 + 볼트 색을 접합점 국소 샘플링으로 재확인. 구조는 맞아도 위치·색이 틀리면 NG |

## 2. 정확도

⚠️ 데이터셋 슬라이드의 "test 149장"은 **디텍션 데이터셋 전체**의 test 분할(낱개 부품 사진
84장 + 피킹 영상 프레임 50장 + 완성 조립체 15장)이다. 룰베이스는 완성 조립체만 판별하는
로직이라, 149장 중 실제 대상은 **15장뿐**이다 — 아래가 그 test 분할 기준 정확도.

### 2-1. test 분할만 (n=15, 정식 수치 — 이걸 발표에 쓸 것)

| 모델 | 정답 / 전체 | 정확도 |
|---|---|---|
| Model A | 3 / 3 | 100.0% |
| Model B | 5 / 6 | 83.3% |
| Model C | 6 / 6 | 100.0% |
| **전체** | **14 / 15** | **93.3%** |

### 2-2. 참고: train+test 합쳐 100장 (완성 조립체 전체 데이터)

test 분할만으로는 표본이 15장뿐이라 참고용으로 train도 합친 값을 같이 둔다 (발표에선
"test 15장 기준 93.3%"를 대표 수치로, 필요하면 "전체 100장 기준 97.0%"를 보조로).

| 모델 | 정답 / 전체 | 정확도 |
|---|---|---|
| Model A | 20 / 20 | 100.0% |
| Model B | 38 / 40 | 95.0% |
| Model C | 39 / 40 | 97.5% |
| **전체** | **97 / 100** | **97.0%** |

## 3. 혼동 행렬 (오분류 유형)

### test 분할만 (n=15)

| 정답 → 판정 | 건수 |
|---|---|
| model_a → MODEL_A | 3 |
| model_b → MODEL_B | 5 |
| model_b → **None(보류)** | 1 |
| model_c → MODEL_C | 6 |

**다른 모델로 잘못 판정한 사례 0건** — 실패 1건도 "정답과 다른 모델로 착각"이 아니라
"애매하니 보류"로만 실패함. (train+test 100장 기준으로도 동일하게 오탐 0건, 실패 3건 전부 보류)

## 5. 처리 속도 (CPU 단일 스레드)

| 항목 | test 15장 | train+test 100장(참고) |
|---|---|---|
| 평균(mean) | 14.0 ms | 13.0 ms |
| 중간값(median) | 12.3 ms | 10.8 ms |
| 최대(max) | 24.0 ms | 24.2 ms |
| **처리량** | **~72장/초** | **~77장/초** |

딥러닝 추론이 없는 순수 classical CV라 가벼움 — ResNet-18 분류 모델(이중검증용)과 비교해
"룰베이스가 훨씬 가볍고 빠르다" 근거로 쓸 수 있음.

## 7. 발표 요약 문구 (개조식)

- test 분할 완성체 사진 15장 중 14장 정답 (93.3%) · 참고: train 포함 100장 기준 97.0%
- **다른 모델로 잘못 판정한 적 0건** — 틀려도 안전하게 보류
- 평균 14ms(초당 ~72장) — 딥러닝 없이 실시간급 처리
- 딥러닝은 "왜 틀렸는지" 설명 불가(블랙박스) → 룰베이스가 원인 텍스트 생성 전담
